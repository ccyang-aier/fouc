# 项目工作台与单侧栏重构

- [x] 单一主导航：品牌、顶层项目切换、新对话；工作台 / 任务 / 成员 / 资产 / 聊天 / Agents；服务 / 标签 / 最近；保留账户、设置和帮助。
- [x] 迁移现有工作台首页，删除项目内第二套导航、旧项目目录与自动化模块及唯一依赖。
- [x] 项目选择 / 搜索 / 新建 / 重命名 / 删除闭环；无项目、加载、失败和无权限状态。
- [x] 项目作用域：身份与项目共同隔离页面、草稿、对话历史及最近；顶部项目是唯一当前项目选择。
- [x] Agents 一级独立页面，复用真实设备发现与连接状态，不在侧栏展开子菜单。
- [x] 知识库开放项目范围：创建默认关联当前项目，owner 配置，前后端按当前项目筛选并叠加既有 ACL。
- [x] 更新权威项目 / 架构 / 身份 / 知识库设计与 AGENTS 资源模型，不保留冲突描述。
- [x] 必要权限与作用域测试、类型与边界检查、真实视觉流程和深浅主题；服务保持 dev 常驻，统一提交。

知识库关联接口：GET `/api/knowledge-bases?projectId=…`；GET/PATCH `/api/knowledge-bases/:knowledgeBaseId/projects`，PATCH `{projectIds: string[]}`。关联只限定可见范围，不代替知识库成员与页面 ACL。

实现分工：主 agent 维护 shell、项目切换、聊天范围、文档和提交；knowledge scope agent 仅维护后端 / shared 权限与数据模型；knowledge UI agent 仅维护知识库前端；cleanup agent 清理旧自动化与旧项目页面，避免共享文件并发覆盖。

## 验证摘要

- 用户确认：只迁移工作台首页，任务／成员／资产先保留空状态；首页记录继续明确为按项目隔离的本机交互样例，聊天历史为应用会话内预览。
- 项目 provider 14 项测试、99 断言；聊天历史 3 项测试。覆盖身份／项目隔离、迟到响应、StrictMode、CRUD 失败、本机存储失败及服务端请求不重复执行。
- 知识库前端 21 项 P0 测试；服务端项目开放范围与既有库权限 6 项集成测试；契约／数据库 schema／RLS 22 项测试通过。数据库 35 张表、30 张强制 RLS 表检查通过。
- 工作台首页 store、链接、图表与语言 28 项测试、217 断言通过；前端／服务端／shared 类型、定向 ESLint、架构边界、i18n、文档和 Web 生产构建通过。
- 真实浏览器核对：项目搜索与无结果、键盘方向选择与关闭回焦、创建表单与取消、工作台账单弹窗、任务空态、聊天／最近同步及重复打开、Agents 真实设备状态、知识库按项目创建、侧栏收起展开、深浅主题及窄窗口布局。未创建遗留测试资源。
- Web、设备 sidecar 与业务服务健康端点均返回 200，开发服务保持运行；本次不构建桌面客户端。
