## 验证范围

仅验证设计交付物与当前代码的外壳依据，不以静态 UX 图声称后端或运行能力已实施。不修改产品代码，不运行无关回归，不构建 Tauri。当前 Web 开发服务用于读取真实外壳并保持常驻。

首页图像由内置 imagegen 生成，五张最终原图、生成提示词与画册保存在 `docs/product/V1/design/projects/assets/add-workflow/homepage/`；公共外壳参考复用上级 `reference/fouc-shell-wide.jpg`。各 agent 仅写各自风格目录，Root 统一维护权威文档和提交。未选草图与临时检查文件在结束前清理，前轮已经交付的原图不在本轮删除。

验证摘要：五张最终图互不重复且 PNG 可解码，各风格目录只有一张选定图；五份提示词记录和共同 brief 均为有效 UTF-8 JSON，画册与文档指向同一组结果。浏览器验证五种风格切换、整页与原尺寸查看，画册保持可访问；JavaScript 语法、62 份 Markdown 的链接与位置、Git diff 空白检查通过。图内工作项、人物、状态和证据摘要均为 UX 场景示例，不是当前产品实现或真实执行证据。
