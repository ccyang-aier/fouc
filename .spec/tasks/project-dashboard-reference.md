## 执行范围

- 直接落在现有 `?view=projects` 项目工作台；选中真实项目后呈现完整 Dashboard 工作面，不新建独立路由。
- 参考人物、任务和统计作为该界面的本机交互样例，状态以当前项目的来源和 projectId 隔离；不创建账户、项目成员或服务端资源，不改写现有项目资源与授权契约。
- 保留视频英文文案、浅色视觉、导航、活动时间轴、项目卡、团队、会议、里程碑和评论弹窗；补全主要按钮与表单的交互闭环。
- Next.js / Bun 开发服务常驻；不构建 Tauri。
