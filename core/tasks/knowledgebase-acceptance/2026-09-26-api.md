# A00 · Hono / tRPC 服务端数据边界

2026-09-26。主代理已阅读全部生产 API 文件并独立运行真实网络/PostgreSQL 回归，验收通过。本项没有把基础身份验证误称为页面 ACL，也没有提前挂到旧全局服务器。

## 实现

- 官方 tRPC 11.19.0 Fetch adapter + 既有 Hono。仅拥有 `/api/knowledge/:workspaceId/trpc` 及其子路径；同前缀组织/认证服务不依赖挂载顺序。
- 受保护 procedure 工厂要求完整 Zod 输入及显式非空 scope；拒绝绕过工厂的公开 procedure/router。URL 与输入 workspace 一致，服务端真实 Session/PAT 上下文无法由 JSON 伪造，Authorization 不回退 cookie。
- 每条 batch procedure 与新租户事务开始前复验凭据/成员；事务 callback 得到最新角色。操作开始时检查不代替 P03 在领域事务内执行 ACL 与撤权围栏。
- 精确 Origin/CORS/CSRF、实际字节计数、有限 JSON/URL/batch、无缓存、无 Referrer，固定脱敏错误与服务端 requestId。错误不包含 SQL、凭据、输入或异常堆栈。
- 真实客户端断连及 R01 停机 signal 传播，取消在 callback 完成前触发回滚；正常完成不误 abort，所有 listener 清理。不是 PostgreSQL wire-level 取消，也不声称能撤销已提交写入。
- 仅 type-only router 接口可进入浏览器，实际 browser-target bundle 为空；扫描器同时覆盖后端 API 与领域目录，禁止 UI 反向依赖和 API 绕过 AI gateway。
