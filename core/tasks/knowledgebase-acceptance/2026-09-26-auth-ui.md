# A04 · 登录、注册、SSO 与会话恢复界面

2026-09-26。界面落地于 `src/features/identity/`（纯逻辑 + 组件 + 场景）与 `src/app/auth/`、`src/app/auth/verify/`、`src/app/auth/callback/` 三个静态导出路由段。全部验证命令在本机真实执行；后端 sidecar `127.0.0.1:8710` 未挂载 `/api/auth`（Z03 才装配），因此**没有真实认证 HTTP 往返**——行为契约以状态机单测 + 浏览器组件级验证覆盖，未验证边界见文末。

## 实现

- **纯逻辑层（可测，React 组件零分支逻辑）**
  - `auth-errors.ts`：`KnowledgeAuthFlowError`（code/httpStatus/serverCode）领域错误。Better Auth 1.7.6 + Fouc 后端可发出的全部脱敏 code（22 个）显式映射到 8 个域码（`INVALID_CREDENTIALS` / `EMAIL_NOT_VERIFIED` / `EMAIL_DELIVERY_FAILED` / `AUTH_UNAVAILABLE` / `RATE_LIMITED` / `NETWORK` / `ENDPOINT` / `INVALID_REQUEST`）；未知 code 5xx 降 `AUTH_UNAVAILABLE`、4xx 降 `INVALID_REQUEST`；无 code 时按状态回退（401→凭证、429→限流、404/5xx→不可用）。`authErrorCopyFor` 只产出固定中文文案，永不回显服务器英文详情。
  - `validation.ts`：镜像 A01 服务端限额——密码 12–128、名称 trim 后 1–120、实用邮箱形态；逐字段中文错误。
  - `return-to.ts`：`returnTo` 净化（仅站内绝对路径；拒绝 `//`、`/\`、外域、scheme、>512；**拒绝 `/auth*` 自身防回环**，含带 query 的变体，`/authbridge` 不误伤）；sessionStorage 存取（`fouc.auth.returnTo`、`fouc.auth.pendingEmail`）、sealed storage 安全降级；`resolveAuthReturnTo`（URL 参数优先 → storage → 默认 `/`）。
  - `oauth-callback.ts`：`?error=` 回调解析（22 个契约 code 白名单，未知降 `oauth_provider_error`；**`error_description` 一律丢弃**，外发文案只按 code 索引）+ 三档可恢复性（retry/switch-way/support）中文文案；`?status=ok` → completed；裸访问 → manual。
  - `verify-callback.ts`：`?status=verified` → 成功；`?error=TOKEN_EXPIRED|INVALID_TOKEN|USER_NOT_FOUND|INVALID_USER`（未知降 INVALID_TOKEN）；error 参数压过 status 参数（后端会把 error 追加到已带 status 的回调 URL 上）；过期/已用提供重发入口，账号缺失不提供。
  - `resend-cooldown.ts`：60s 客户端冷却（严于后端 5 次/分钟），纯函数边界判定。
- **数据层 `auth-api.ts`**：原生 fetch（登录流非 tRPC）客户端。origin **复用** `src/features/knowledge/data/endpoint.ts` 的 `getKnowledgeApiOrigin`（桌面 Tauri 命令 / `NEXT_PUBLIC_FOUC_API_URL` / dev 回退 8710），路由固定 `${origin}/api/auth/*`；`credentials: 'include'`、POST 恒 JSON、`cache: 'no-store'`；非 2xx 读 `{code}` 归一为 `KnowledgeAuthFlowError`；providers 列表做防御性形状过滤。响应体中的 session token 一律忽略不存。
- **会话恢复 `session.ts`**：`isUnauthorizedKnowledgeError`（识别 U01 `KnowledgeDataError` 的 UNAUTHENTICATED/401）、`redirectToKnowledgeSignIn(reason)`（保存当前路径为 returnTo → 顶层跳 `/auth?reason=expired`）、`performKnowledgeSignOut`（POST `/sign-out` → 清本地 → 失败如实报告但仍清理）、`signOutAndReturnToSignIn`、`fetchKnowledgeSessionUser`（按需重验会话，失败抛归一错误供重试）。
- **UI（design tokens + Radix 风格 Button + motion 克制过渡）**
  - `auth-scene.tsx`：居中舞台（accent 径向光 + 点阵网格、mask 渐隐）、Fouc 标志锁定行、`overlay-surface` 卡片、300ms ease-out 入场；`MotionConfig reducedMotion="user"`。全部颜色走 `--shell/--panel/--accent/--ink` 等令牌，深浅主题与自定义主题色即时生效。
  - `auth-field.tsx`：标签 + 输入（设置页同款 6px 圆角/令牌边框/accent 聚焦）+ 错误/提示行，`aria-invalid`/`aria-describedby`/`role="alert"` 接线。
  - `auth-status.tsx`：四色内联状态条（error=assertive alert，其余 polite status）。
  - `sign-in-form.tsx` / `sign-up-form.tsx`：客户端校验门 + 提交态（spinner/禁用/aria-busy）；登录错误统一文案（不区分用户不存在/密码错误）；`EMAIL_NOT_VERIFIED` 切换到"邮箱尚未验证"重发子状态；注册成功态文案严格采用 A01 语义：**"注册请求已受理，请查收验证邮件；未收到可重发。"** + 冷却重发 + 1 小时有效期说明。
  - `resend-verification.tsx`：共享重发入口（60s 倒计时禁用、429 警示文案、受理式成功文案不承诺送达）。
  - `oauth-provider-list.tsx`：`GET /api/auth/oauth/providers` 拉取 `{id,name,kind}[]` 渲染按钮（OIDC/OAuth 徽标、加载骨架屏、错误 + 重试）；点击 `POST /sign-in/social` 取 `{url}` 后**顶层导航**到授权 URL（跳转前持久化 returnTo；callbackURL=`/auth/callback?status=ok`、errorCallbackURL=`/auth/callback`，均按页面 origin 构造绝对地址以满足 trusted-origin 校验）。
  - `knowledge-sign-out-button.tsx`：登出按钮（供 Z03 挂载到用户菜单），失败态可见反馈。
  - 场景：`auth-entry-scene`（登录/注册 AnimatePresence 切换、reason 提示、Esc 取消注册、providers 区、模式深链 `?mode=sign-up`）、`verify-email-scene`（四态）、`oauth-callback-scene`（错误文案 + 重新登录/返回首页；completed 态先 `get-session` 重验再 700ms 后恢复 returnTo；验会话失败可显式重试）。
- **路由挂载**：`src/app/auth/page.tsx`、`src/app/auth/verify/page.tsx`、`src/app/auth/callback/page.tsx` —— 各自 Suspense 包裹 `useSearchParams` 客户端场景，附同构降级 fallback 与页面 metadata。

## 未验证边界（诚实记录）

- **无真实认证 HTTP 往返**：8710 未挂载 `/api/auth`（curl `GET /api/auth/oauth/providers` → 404，浏览器内为 CORS 阻断 → NETWORK 态）。注册受理、验证邮件链接回跳、OAuth 授权 URL 顶层跳转、Cookie 会话建立/撤销、`EMAIL_DELIVERY_FAILED`/`AUTH_UNAVAILABLE` 真实触发，均留给 Z03 装配后验收；当前界面展示的是这些路径的归一错误/加载/冷却状态机。
- **returnTo 端到端恢复未在真实 401 流程中演练**：净化/存储/消费逻辑由单测覆盖，`redirectToKnowledgeSignIn` 到工作台的接线归 Z03（本任务不拥有 `src/shell/`）；`/auth?returnTo=…` 的解析链已在组件中生效（单测 + 深链验证）。
- **OAuth callbackURL 的跨源信任**：界面按页面 origin 构造绝对回调地址；跨端口 dev / Tauri WebView 场景要求 `FOUC_AUTH_TRUSTED_ORIGINS` 包含前端 origin（认证 README 的部署契约），属 Z03 配置，未在此验证。
- **登出按钮未挂载到应用壳**：`KnowledgeSignOutButton` / `performKnowledgeSignOut` 已实现并单测（含失败态），等待 Z03 放入用户菜单。
- 浏览器验证使用与并行任务共享的 Playwright CLI 实例，已关闭自己创建的标签页；`.playwright-cli/` 为 gitignored 工件目录。
