# V02 · 块与行内历史差异算法

2026-09-26，已实现并验证。纯共享模块 `shared/src/knowledge/history/` 比较同一 Schema 下两份真实 ProseMirror 快照；不导入 React、后端、Y.Doc 存储或平台 API，不修改原文档。

- 以有效且唯一的 blockId 匹配，分别报告新增/删除/移动/类型/属性/marks/行内修改；拒绝缺失/重复身份，不悄悄生成新 ID。每项提供两份快照中的 parent/index/path 与准确半开 PM 范围。
- 同父顺序使用 O(n log n) LIS 得到确定性的最少移动解释，插入/删除造成的位置偏移不会误判；容器移动不重复标记每个子块，子块文本修改不把整条祖先链标成正文修改。跨父移动可与内容编辑并存。
- 行内以 grapheme 与不可分割的 inline atom 比对，marks/评论/建议/链接目标参与相等性；保留 UTF-16 坐标、中文、emoji ZWJ/肤色、组合字符、换行/空白，不做有损归一化。
- 共用全篇 LCS 单元格预算，超限明确标成 coarse，仍返回准确覆盖变更的范围；不声称粗粒度结果是最小差异。无二次方无界矩阵。

**166 项共享回归通过；V02 单独 20 项测试在 Bun 和纯 Node 均通过**。包括五块全部 120 种排列的独立穷举最少移动核对、120 组确定性文本变更的范围重建、两种 diff 精度预算、全部 27 种一方块的真实 M01 Markdown 往返、自定义块、嵌套表格、空段落与相邻同版本。类型检查与定向 lint 通过。

范围：这不是历史 UI、检查点持久化、页面授权或协同恢复的验收；分别由 V03、V01、P03 与恢复流程完成。diff 范围仅对应输入快照，不可直接视为对实时文档的写权限或可用位置映射。没有 Tauri 构建，Web dev 保持运行。
