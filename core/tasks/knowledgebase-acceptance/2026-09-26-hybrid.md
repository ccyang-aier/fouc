## 架构（§7.2 混合检索）

- **单一入口**：`searchHybrid(pool, { gateway, embedBinding, rerankBinding?, workspaceId, principals, query, userId, limit?, signal? })`，返回统一契约 `HybridSearchResult`（hits + `vectorLeg` + `rerank` 状态），供搜索框、AI 问答与 MCP search 工具共用。签名取 `pool` 而非事务句柄：查询向量（embed 档）与重排（rerank 档）两次模型调用必须在租户事务之外（H02 同款纪律），两腿 SQL 共用一个短事务取得一致快照。
- **各取 50 → RRF(k=60) → 前 20 重排**：关键词腿 `searchBlocksByKeyword(limit 50)`（BM25 分数序、id 决胜）与向量腿（`embedding <=> q` 距离序、id 决胜）各自 cap 50；融合分 `Σ 1/(60 + rank)`（rank 按腿内名次，1 起）；RRF 决胜链：分数降序 → 最优单腿名次升序 → `pageId:blockId` 字典序（全程确定）；融合前 20 交 rerank 档，`limit`（默认 20，上限 20=重排候选集）截断最终结果。
- **重排文档**：候选块的 `embeddingInput(titlePath, contentMd)`（与向量模型同源上下文），单文档截断 8,000 字符（20 候选远低于网关 1MiB 共享预算）；`topN` = 候选数。模型未返回的候选按 RRF 序续于已排序之后（`rerankScore: null`）。
- **降级语义（显式标注）**：`vectorLeg` = `used{model,dimensions}` 或 `skipped{no_active_model | binding_mismatch | embed_unavailable}`——无生效模型/绑定与生效模型不一致（H02 防混模型的查询侧孪生）/查询向量生成失败时只走关键词腿；`rerank` = `applied` 或 `skipped{no_candidates | not_configured | provider_failed}`——无绑定或供应商不支持（网关 `configuration`/`unsupported_capability`/`credential_unavailable`）跳过并**保持 RRF 序**，供应商故障（鉴权/限流/超时/响应非法）同样不致失败、按原因标注；调用方信号中止（`cancelled`）原样上抛。命中级 `rerankScore: null` 标注未覆盖。
- **向量腿 SQL 形态（谓词先于排序）**：权限谓词（`indexedBlockAccessCondition`：workspace + principals 交集 + 回收页 + ACL 版本守卫）、当前模型过滤（`embed_model = m AND embed_dimensions = d AND embedding IS NOT NULL`，来自 `readActiveEmbeddingModel`）与 `ORDER BY (embedding::vector(d)) <=> $q LIMIT 50` 在同一查询内——无权行与旧模型向量既不进结果也不挤占名次。查询向量由网关 embed 档以生效模型生成（先读标记、事务外调用、维度不符即跳腿）。

## 向量物理索引（按模型表达式 HNSW）——为什么不进 schema，起点在哪

开发库（ParadeDB 16.x + pgvector 0.8.x）实测：

- 无固定维度的 `vector` 列**不能**直接建 HNSW：`CREATE INDEX ... USING hnsw (v vector_cosine_ops)` 报 `column does not have dimensions`（临时表实测）。`block_index.embedding` 按设计无维度（模型无关存储），静态 HNSW 不可表达。
- 唯一正确形态是**按模型表达式部分索引**（临时表实测可建、可随行更新进出）：
  ```sql
  CREATE INDEX CONCURRENTLY block_index_hnsw_{model}_{dims}_idx
    ON knowledge.block_index USING hnsw ((embedding::vector({dims})) vector_cosine_ops)
    WHERE embed_model = '{model}' AND embed_dimensions = {dims};
  ```
- 查询侧配合（2,000 行实测 EXPLAIN）：ORDER BY 必须逐字使用索引表达式 `(embedding::vector(N)) <=> $q` 才会走 `Index Scan using ...`（参数化谓词在自定义计划中代入常量，部分索引可用）；裸 `embedding <=> $q` 一律回退 Sort+Seq Scan。`service.ts` 的向量腿即按此形态书写——无索引时同一表达式退化为精确距离扫描，语义不变，索引建成后自动受益。
- **建索引起点**：该 DDL 是运行期事实（模型身份与维度在 H02 切换提交后才确定），且 `CREATE INDEX CONCURRENTLY` 不能进事务（不能进 schema 源/`current.sql`/init 单事务，也不能进 H02 的切换事务），应用角色按 D01/D03 边界无 DDL 授权（「不要把管理连接交给业务服务」）。因此归属持有管理 DDL 的部署/维护通道（与 `knowledge-db init/check` 同级），在 H02 切换提交后为生效 (model, dimensions) 创建；本任务交付与其逐字兼容的查询形态。旧模型的空部分索引无害（谓词不再命中即自动排空，切回旧模型可复用）。

## 通过的实际流程（逐条对应验收标准）

1. **HNSW 限当前模型**：测试 2 先以 alpha(8 维) 重建，再把标记直接指向 beta(16)（H02 原子切换在产品上排除该状态，此处为验收条款的防御性验证）——16 维查询在无过滤时会因维度不符报错，`(model, dimensions)` 谓词下向量腿干净空返、关键词腿不受影响；绑定与生效模型不一致 → `binding_mismatch` 跳腿；经真实 `rebuildWorkspaceEmbeddings` 换到 beta 后向量腿恢复且 `semanticScore ≈ 1`；无标记 → `no_active_model`。
2. **各取 50 / RRF 60 / 前 20 重排**：测试 1 以可控向量构造语料（关键词命中块、向量独占块、双腿块、重建后才索引的纯关键词块），实测融合序与手算 RRF 分逐一吻合（双腿块 1/61+1/62 居首，纯关键词块 1/64、末位向量块 1/65 分列其后），`sources`/`keywordScore`/`semanticScore`/`rerankScore` 逐项断言；测试 5 以 30 个融合候选实测 rerank 恰收 20 文档、结果恰 20 条、`limit>20` 抛 `TypeError`。
3. **查询前授权**：测试 3 中无权块同时在两腿占第一（BM25 最强 + 距离最近），读者视角两腿均不见该块、自己的弱块在可见集内双腿第一，空主体集合零结果——「先过滤后排序，top-k 不被无权行挤占」在两腿同时成立。
4. **统一结果契约**：`hybridSearchResultSchema.parse(result)` 全部通过（6 个用例），`HybridSearchHit` 基于 `KeywordSearchHit` 扩展（`score` 拆为 `keywordScore`/`semanticScore`/`rrfScore`/`rerankScore` + `sources` 腿标记），API/AI/MCP 共用 `searchHybrid` 单一入口。

## 明确边界

- **向量腿是 nearest-50 名次序而非阈值过滤**：当前模型的全部有权向量行都会进入候选（距离仅定序），语义弱相关块靠 RRF 名次与重排压制——设计如此（§7.2），测试 1/2 的命中集均按此断言。若产品后续需要相似度下限，属新需求。
- **按模型 HNSW 的创建动作未落地**：查询侧已交付索引兼容形态与实测依据（见上节），管理通道的建索引脚本/命令与「切换完成后自动触发」的产品接线属部署侧后续任务。
- **常驻接线**：tRPC 搜索端点、AI 工具层与 MCP `search` 工具对 `searchHybrid` 的组合根注册属后续任务；本任务交付服务入口与共用契约。
- **查询分词事实**（实测 `::pdb.jieba` 与 `@@@`）：空格分隔的查询段按 OR 析取，每段内 jieba 多 Token 为相邻短语——例如 `氦闪探测` 是短语（无命中），`氦闪 探测` 才能各自命中。测试语料按此构造；该语义属 H03 已提交行为，H04 未改动。
- **检索期间的并发**：两腿共享一个快照事务，关键词候选的正文回填在第二个短事务内重走权限谓词，页在两事务间被删除/收权时该候选被诚实地丢弃（不产生越权快照）。
- **空查询**：空白或 >200 字符的查询抛 `TypeError`（两腿都无法执行的调用方错误）；H03 对空白返回空数组的行为保持不变。
