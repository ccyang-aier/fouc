# M01 · 标准 Markdown 双向管线验收

日期：2026-09-26。范围：shared 无框架纯正文转换，不代表导入 UI 或 AI 编辑协议已完成。

## 实现

- `createMarkdownPipeline` 使用同一块/mark 注册表构建 CommonMark/GFM、directive、math 与 wiki tokenizer，提供字符串与 mdast 两个边界的双向 API。
- 27 种一方块、10 种 marks、嵌套列表/表格/列布局、块身份/来源与建议 annotations 可往返。列表变体、任务编号与表格对齐由共享 schema 定义。
- 优先生成可读 GFM；不可原生表达的结构使用可编辑指令，`fouc-meta` 仅补充属性/marks，不存储整篇文档 JSON。导出用真实解析器验证完整文档相等，损失则明确失败。
- 空白/控制字符、相邻同类容器、重叠 marks、格式化代码、媒体、行内数学与 wiki 转义均有回归用例。非法元数据路径/属性、未知指令与未支持输入明确报错，不静默丢弃。

## 边界

- 不分配或修复 blockId：导入者使用 E02 的唯一身份 API。
- 不生成 AI `{#b:…}` 或媒体派生文本：属于 M02。
- HTML、footnotes、未建模 fence metadata 与 wiki embeds 当前显式拒绝；归档/frontmatter/资源解析属于 M03/M04，不冒充已支持。
- GFM 语法风格规范化；混合任务列表拆成同质相邻列表，行内图片提升为有序块，保留正文语义。
- 大文档吞吐与复杂恶意输入预算需在 Z08 实测；本次验收不声明性能指标。

## M02 · AI 方言与可信块映射

日期：2026-09-26。主代理复核 AI tokenizer、tree decoration、scan/strip、context/read、公开类型及管线变更。

- `dialect: 'ai'` 在同一标准管线上装饰全部 27 块的 `{#b:id}`，包括列表/表格结构节点；标准输出不受影响。
- `createAiContext` 以权威 PM 文档和 C01 派生资源产生不可变快照；绑定包含 PM path/range、Markdown carrier、anchor 精确范围、parent 和派生区。`read(range)` 只从该快照按文档顺序读取，并拒绝未知、重复或非法 ID。
- 同实例 opaque context 验证防止模型伪造映射；移动/缺失/重复锚点、修改源内容及重绑定派生区明确失败。派生文本转义为只读引用，整树移除后才交给 PM 解码器，不能成为编辑目标。
- 真实 remark/PM 往返覆盖富表格、marks、建议 attrs、嵌套媒体、浮点转写时间、恶意文本、调用方 mutation 与 GFM cell 范围稳定性。

主代理重新执行 `bun test shared/src/knowledge/schema shared/src/knowledge/markdown shared/src/knowledge/collaboration`：**157 passed / 0 failed**（AI 50、标准 Markdown 55、schema 41、collaboration 11）。共享及后端严格类型检查通过；页面 `http://localhost:3000/` 返回 HTTP 200，未重启 Web 服务。

边界：这是只读上下文投影，不是 AI 写入解析器；权限、修订新鲜度和写事务由后续任务负责。列表/表格 carrier 可重叠，以精确 anchor/path 区分；片段不含完整 metadata，不能独自代表语义 hash。M02 不执行模型预算或悄悄截断；W04/H01/G01 必须先去除/解析内嵌资源并施加明确硬预算，保留来源和时间戳。
