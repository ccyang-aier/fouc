## 通过的实际流程（逐条对应验收标准）

- **link 主体令牌哈希**：创建响应明文恰好出现一次（`body.split(token).length === 2`）；DB 行只存 `sha256(token)` hex 且全文不含明文；`token-format.test.ts` 覆盖解析拒绝（前缀/UUID/密钥长度/非规范 base64url）、等长摘要常数时间比较、缺失凭证不抛错。
- **到期/撤销/级别限制**：到期在凭证核验处用 `clock_timestamp()` 判定——把 `expires_at` 改为过去后链接立即失效且**零** ACL 事件（无需围栏）；创建时过期时间须晚于当前时刻（否则 400）；撤销 = `revoked_at` + 删除 `page_acl(link:id)` + 子树围栏，重建前即 fail closed（页面与 block 双路径 0 命中），幂等二次撤销 `pagesInvalidated: 0`；级别仅 `view|comment`（edit/full/admin 输入 400），降级围栏后重建为低级别，已撤销链接改级别 409。
- **页面及附件同权**：link 主体进 `page_acl` → 物化数组覆盖目标页及子树（含继承断开处截断）；`block_index.principals` 随 `acl.changed` 重建同步，测试用 `effectivePageAccessCondition`/`indexedBlockAccessCondition` 同时断言页面与同页内容块对链接主体可见/不可见——附件与页面共用同一主体谓词。
- **不获得 workspace 全部成员主体**：`verifyShareLink` 的主体集合经 `expandPrincipals({ userId: null, member: null, groups: [], links })` 恰为 `['link:<id>']`；在 teamspace 默认 `view` 的空间里，链接持有者对共享子树**之外**的根页/兄弟页一律拒绝（真实成员经 workspace 主体可看），resolve 响应不含任何成员/页面清单信息。
- **授权接口集成证据**（真实 HTTP + 一次性 PG + 真实 Better Auth 会话）：创建（201/令牌/哈希/围栏/outbox 事件）、使用（子树内按级别放行、越级拒绝、围栏期拒绝）、到期（时间失效、无 ACL 扰动、过期输入 400）、撤销（成员无 full 403、撤销即时生效、幂等）、降级（comment→view→comment、无变化 no-op、撤销后 409）、越权创建（edit 级成员 403、非成员 401、无 Cookie/带 Authorization/恶意 Origin 分别 401/401/403、未知字段与未知页面 400/404 且无行写入）、跨租户（令牌定位段决定租户：α 令牌配 β 页面/β 令牌配 α 页面均拒绝；在 β 库伪造与 α 相同 linkId + 哈希的令牌也拿不到 α 访问）、重建窗口（围栏未重建时二次创建 503 SHARING_REBUILDING，重建后成功）、错误消毒（SQL canary 触发器 → 503 固定响应、正文无 canary、`Cache-Control: no-store`）。

## 明确边界

服务层为 `createShareLinkService`（A03 同款 Request 级服务，测试经真实 HTTP 挂载验证）；生产路由挂载、分享管理 UI 与公开分享页属 U05。附件二进制字节流端点属 media/T01+（本任务保证其权限谓词对 link 主体成立）；MCP 侧 link 主体接线属 J02。未提供链接列表接口（无验收需求）；链接级别永远不可能为 edit/full，链接管理永远要求有效 `full` 且仅限会话凭证。
