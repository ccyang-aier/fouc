## 九、维护这份调研时的更新规则

1. 每月检查 MCP、A2A、ACP、AG-UI 的规范版本和主要客户端实现矩阵；
2. 每季度重新核对 Coding Agent 的产品形态、开源许可、企业控制和成熟度标签；
3. 产品自述新增能力时，至少等待官方文档或可运行版本，不只引用发布会；
4. 定价、额度、模型清单和区域可用性单独维护，不写进长期架构结论；
5. 预测实现后移入时间线；预测失败时保留记录并说明原因；
6. 对生产率结论记录样本、任务、工具版本和指标，避免跨场景外推；
7. 中国版与全球版产品必须分别核对主体、条款、模型、网络和数据处理。
