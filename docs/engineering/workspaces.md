# 工作空间服务

本模块是 Fouc 全局工作空间与成员关系的唯一业务入口，管理工作空间、成员、群组及邀请。`createWorkspaceService(pool)` 使用服务端认证生成的身份，事务内重新核对会话、用户和当前成员角色；请求 body 中的 userId 只能表示被管理对象，不能充当操作者身份。

工作空间是隔离根。项目和知识库均直接归属工作空间、彼此同级，服务端用例不能将一者当成另一者的容器。全局工作空间列表仅发现当前用户有成员资格的空间；对空间内资源的读写另由对应业务模块进行权威授权。个人和团队空间使用同一资源与事务路径。未登录并不意味着切换成另一套知识库页面。

HTTP 路径为 `/api/workspaces`，提供空间列表与创建、空间成员与群组管理、邀请接受等操作。工作空间发现使用只读身份上下文；业务操作使用 `withWorkspaceTenant` 的租户事务，不允许客户端传入身份或绕过工作空间作用域。写请求要求 JSON 与可信 Origin。

验证：`bun test backend/server/src/modules/workspaces`，并运行 `pnpm server:typecheck`。
