# Fouc 界面国际化

Fouc 当前支持简体中文（`zh-CN`）和英语（`en-US`），首次使用默认简体中文。通用设置中的语言配置即时作用于整个界面，并保存为设备级偏好；登录、退出或切换项目不改变语言。Web 使用本机浏览器存储，与现有外观偏好遵循相同生命周期。

## 文案所有权

语言基础设施位于 `src/lib/i18n/`，负责语言订阅、偏好、词条选择、命名参数插值以及 Intl 日期、数值和复数格式。功能模块拥有自身词条；按菜单、弹窗、编辑器工具或界面单元拆分，不使用一个包含全产品文案的巨型字典。每条词条包含中文与英文，词条键由 TypeScript 检查；占位参数必须在两种语言中保持一致。`{name}` 表示插值，`{{name}}` 表示代码、公式等示例中的字面花括号；替换值始终作为普通字符串处理。

可见标题、动作、辅助说明、校验、Toast、菜单、空状态、可访问名称和导出表头都属于界面文案。产品名、技术标识、文件内容与用户输入不属于界面翻译。数据库类型、SQL、项目和知识库 ID、URL 参数、状态枚举、权限代码、连接信息等继续使用稳定协议值，界面通过独立标签呈现。

知识库列表的来源与索引状态保存 canonical code；列表、卡片和 CSV 导出在呈现时选择对应语言。项目内置演示内容通过明确的记录 ID 与字段值确认所有权，用户编辑过的字段直接呈现原文。不能通过匹配任意中文或英文字符串反查词条。

跨宿主共享验证器通过 `ValidationIssue` 提供稳定 `code`、原始 `values` 和默认诊断 `message`，异常保留同一 issue。设备 API 的错误响应通过 `error.validation` 传递，前端 `BackendRequestError.issue` 保留结构，由所属连接器验证单元按 code 选择双语词条。嵌套 issue 在呈现时格式化，未知错误及外部诊断保留原文；不能根据中文错误字符串推断操作或复制校验逻辑。结构化错误不改变验证条件、权限、资源归属或实际执行参数。

## 切换与状态

语言变更经外部存储订阅更新；组件不以语言为 key，不重新挂载页面、编辑器或弹窗，不清空草稿、选择与滚动位置。React 渲染使用 `useTranslation` 的语言快照，以默认中文服务端快照保证水合一致；从本机恢复英语后再更新显示。纯函数在渲染时接收组件语言，事件执行时可读取当前语言。

静态菜单保存消息键或由显式语言 factory 产生标签，不能在模块加载时求值翻译。日期、时间、货币、数字和复数按语言格式化，原始数值、时间戳与时区语义不改变。来自用户或外部服务的正文保持原文；演示数据只有明确属于内置演示内容的字段可拥有双语展示，编辑后保留用户原文。

富文本编辑器通过现有实例更新界面属性，再派发不进入撤销历史的语言事务，以刷新 slash、评论、审阅等插件。CodeMirror 通过 Compartment 更新搜索、折叠、补全和可访问名称，不重建查询文档。持续错误保存消息键、原始 cause 或结构化 issue，在渲染时按当前语言呈现。连接器单元通过绑定自身 catalog 的消息工厂生成描述符，支持嵌套提示；直接传入的字符串和外部错误始终保留原文。

`html.lang`、页面标题与描述随语言更新。语言偏好同步到其他已打开的同源标签页；浏览器拒绝保存时，当前会话仍应用所选语言，并在设置中提示未能保存。

## 扩展与验证

新增界面应同时提供两种语言，复用现有语言层和模块词条。`pnpm i18n:verify` 校验词条完整性、参数一致性和静态调用的插值参数；状态恢复、权限语义与编辑器实例由必要单元测试和真实页面流程验证。技术或用户内容的例外须有明确所有权，不能通过任意文本的 DOM 替换或运行时机器翻译覆盖整个页面。
