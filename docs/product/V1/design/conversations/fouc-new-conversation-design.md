# Fouc New Conversation

新对话主页面保留 Fouc 原有导航壳，以紧凑上下文工具栏、输入卡和模型／Agent 选择菜单组织任务入口。输入卡与附件交互沿用 `opensource/dribbble/produtc-design-02.mp4` 的正向交互参考；上下文工具栏和执行选择菜单以当前用户提供的静态截图为视觉依据。

## 页面与状态

初始页采用主题面板背景、居中衬线问候、轻描边圆角输入卡、底部附件及模型／Agent 入口、右侧麦克风及深色语音按钮。问候标题与输入卡共用水平中轴，不显示额外图标。进入初始页时使用一次打字机效果：延迟 160 ms 后每 90 ms 逐字显示，细光标跟随当前字符，句末闪烁三次后隐藏，完整标题保持常显。按最终文字预留布局宽高，避免逐字出现时居中位置和下方输入卡跳动；中英文沿用同一文案目录，窄屏保留正常换行。标题提供完整无障碍名称，视觉字符对辅助技术隐藏，不逐字播报。动画由 CSS 完成，没有运行计时器或逐字 React 状态更新；减少动态效果偏好直接显示全文并隐藏光标。附件、模型、麦克风和发送按钮统一使用 `--chat-control-border` 浅描边（全局控件描边与面板按 40% / 60% 混合），发送按钮保持深底。输入卡顶部为全宽 40 px 浅灰上下文工具栏，项目和知识库位于左侧，右侧齿轮展开本地环境菜单；删除深度研究、部署 Agent 和更多建议动作。输入区最小高度 86 px、底部操作按钮 30 px，保持输入卡全宽。附件菜单在入口下方展开；真实文件显示类型、文件名、大小和红色移除操作。文件卡进入约 240 ms，输入文字后语音图标切换为朝右上 45 度的实心纸飞机约 170 ms，提交后输入区移到会话底部约 480 ms。工具入口悬停不添加底色，仅将右侧小箭头向右移动 3 px；减少动态效果偏好关闭这些动效。

项目选择来自 `features/project` 的真实目录，菜单提供搜索、当前选择、新建项目和不在项目中工作；新建复用项目资源用例，名称输入与真实保存状态在菜单内完成。已选项目及无项目状态使用右侧勾号，底色仅表示当前鼠标或键盘目标，不能同时把已选项画成 hover。输入卡中的未选入口显示“选择项目”；选中后显示项目名，悬停或键盘聚焦时，左侧文件夹切换为圆形取消图标，名称与宽度不跳动。取消按钮与项目菜单入口为相邻独立按钮，不嵌套；点击仅清空当前对话项目上下文，恢复入口焦点并通过 AppAlert 反馈，不打开菜单或删除项目。触屏直接显示取消入口。项目和知识库入口的 hover 使用共享浅灰反馈面（--action-surface-hover-bg），取消图标所在热区也保持整条胶囊反馈。选择只影响本次对话上下文，不更改项目授权、文档归属或资源权限。项目与知识库弹窗共用 224 px 宽、12 px 圆角、12 px 正文、28 px 行高和 36 px 搜索栏，在工具栏上方展开。知识库入口与项目共用同一胶囊组件、整行 hover／键盘反馈和左侧圆形快捷取消按钮；未选择时显示“选择知识库”，清除后恢复入口焦点并通过 AppAlert 反馈。知识库菜单提供同样的搜索栏、资源图标、右侧勾选、空结果和不使用知识库入口；仍保持首页知识上下文演示的边界，不冒充真实知识库目录或 ACL。

输入卡上方为 plugins 快捷行，初始页与会话输入区共用：构建网站、开发桌面应用、制作幻灯片、设计，以及“更多”中的写作、研究、数据分析。按钮为 28 px 高的紧凑虚线圆角胶囊、15 px 图标、12 px 文字、10 px 横向内边距，按钮间隔 6 px、行下方留 10 px。hover、聚焦和选中使用与 plugins 引用一致的明亮浅蓝色：浅色为 `#e9f5ff` 底、`#bee2ff` 边框、`#096eaf` 前景，深色为 `#0d304b` 底、`#1a608b` 边框、`#81d0ff` 前景；保持共享操作状态反馈。点击保留 240 ms 的 1→0.95→1 微收缩回弹，减少动态效果偏好关闭动画，窄屏自然换行。快捷行与 plugins 菜单引用社区模块提供的同一批稳定插件 ID，可多选、再次点击取消，任一入口和标签移除均同步更新其他入口。插件与 skills／MCP／prompts 统一进入输入框上方的资源标签行，不再在正文第一行单独显示任务标签。选择不改动正文、附件、模型或授权；提交和编辑通过同一份资源引用快照恢复，新草稿与新对话清空引用。输入 placeholder 保持 muted，正文保留原生 textarea 的编辑、粘贴、语音和提交行为。插件目录与会话仍为界面预览，不代表已安装插件或完成产物生成。

模型／Agent 共用一个可搜索菜单，新对话默认使用模型 Auto 模式；打开菜单时显示当前选择所属列表，并将已选项滚入视口。右上角以大脑和简洁机器人图标切换列表；切换列表不直接更改选择，点击列表项才保存执行类型；具体模型和 Agent 同时保存唯一 ID 与名称快照，入口和提交后的上下文摘要显示对应名称。打开时以共享菜单背景条标识已选项；鼠标或键盘进入其他行后，背景条只跟随当前交互行，不展示选择勾号。Auto 是独立的自动选择意图，不伪装成服务端目录中的具体模型；实际自动路由随统一任务下发用例接入。Auto 位于模型列表顶部，使用黑底、柔和曲线构成的白色四角星，即使目录加载失败也可选择；具体模型按 OpenAI、Anthropic、Google、DeepSeek 分区，仅显示有结果的供应商。搜索同时筛选模型名称、供应商和 Auto，空结果不保留空分区。

Auto 悬停、键盘方向键或触屏点击复用模型左侧资料浮层，采用独立 300 px 宽的紧凑面板，直接展示简短说明与一行候选模型配置入口，移除重复的 Auto 图标和标题行。默认不展示模型长列表、全选工具栏或底部说明；点击入口后展开 28 px 单行候选列表，删除重复供应商副标题，收起后显示全部模型或已选数量。候选项来自服务端模型目录，支持勾选、全选、重置和必要的异常反馈，至少保留一个当前目录模型。`autoRules.modelIds = null` 表示全部目录模型，显式数组限定候选模型 ID；修改立即记录当前对话草稿，提交和编辑保留规则，切换具体模型或 Agent 不丢失该偏好。规则不代表已获得模型执行权限，也不产生真实调用。

参考截图用于还原比例、材质和布局，不将截图的物理像素直接作为 CSS 尺寸。模型弹窗为 324 px 宽、32 px 无边框搜索栏、13 px 正文、34 px 行高、18 px 品牌图标，列表最高 340 px；搜索栏压缩为 32 px 高，整行含分隔留白为 37 px；使用 muted 提示色和底部浅色分隔线，聚焦时不增加阴影、ring 或外框。弹窗沿用轻边界、层次投影和浮起的白色分段选中面。列表和资料卡滚动条贴近浮层右边框，正文独立留白；窄屏详情覆盖列表时，列表滚动条留在自己的绘制层内。模型行依次展示厂商图标、名称及紧邻名称的生图／视频生成图标、中部 52×20 px 柔和调用曲线、最右侧上下文长度；名称可以截断，能力图标保留。曲线采用明亮青绿、1.5 px 圆端线，近一周等时段样本聚合为最多 8 个趋势点，再以连续三次 B 样条消除毛刺。悬停曲线仅展示“最近一周调用次数”和“最近一周总吞吐 Tokens”两项，总吞吐包含输入与输出 Tokens；点击曲线不选择模型，行级无障碍描述也提供统计。当前使用按 modelId 稳定生成的演示数据，28 个六小时桶覆盖一周，周调用次数等于桶内次数之和；`UsageSeries` 明确区分 mock/live，无障碍描述与曲线原生提示标识演示状态，后续真实聚合数据复用同一组件，尚无调用计数服务。Auto 行使用相同曲线与最右侧上下文布局：曲线及统计汇总当前候选池，右侧显示该池最大已知上下文，候选池不受搜索过滤影响；候选池为空时统计为零、上下文为“—”，未知上下文不伪造数值。图片能力图标保持绿色，视频能力图标使用低饱和紫色。

模型元数据由业务服务公开目录提供，所有权和数据规则见[模型资料目录](../agents/fouc-model-catalog-design.md)。展开菜单时读取，选择模型后保留查询缓存；多个输入区去重请求，缓存有效期 15 分钟。首次加载、请求失败重试、空目录与无搜索结果有各自反馈，服务错误不能静默替换为示例目录。Nova / Codey / Sage 仍是演示 Agent，不伪造其实际安装或可用能力。

选择支持离散思考档位的模型后，模型入口右侧显示独立的推理强度按钮，两个按钮各自具有完整浅描边、8 px 圆角与 30 px 高度，之间保留 8 px 间隔，不绘制共同外框；推理按钮显示大脑图标与当前强度。展开内容基于 [claude-range-slider](https://github.com/254558/claude-range-slider/tree/e79b9ac) 原项目，外层为 264 px 宽、约 91 px 高、14 px 圆角、上下 10 px／左右 12 px 内边距；标题 12 px、下方间隔 8 px，仅显示“推理强度”，删除标题右侧当前值和“更快响应／更充分思考”提示行。滑块下方按模型实际支持的档位显示小写英文标识（如 low、medium、high、xhigh、max），10 px muted 文字在轨道下方间隔 5 px，与各档滑块中心对齐；当前档位即时变紫色并使用 600 字重，其他档位保持灰色，不添加目录未支持的档位。标题、入口按钮与原生 range 的当前值描述共用应用国际化，默认中文；下方档位使用真实英文标识。窄视口约束卡片宽度以保留安全间距。浅色主题外层为白色背景、轻描边与适配灰度文字，深色主题保留黑色卡片；保留原始 squircle 裁切；外层阴影收为 4 px／12 px／8% 与 1 px／3 px／5% 两层轻投影，减小阴影扩散和不透明度。

滑块深色轨道高 26 px，白色滑块宽 29 px、高 25 px，横向几何与档位对齐保持不变；保留源项目五个圆点与 GLSL 着色器；渲染仍使用原始四阶段 WebGL2 模拟、水平模糊、垂直模糊与合成，保持原始时间、亮度、星点密度与光晕参数。仅最高档启动星光；其他档位保持原项目深色轨道，画布裁切采用原项目的当前位置加 2% 规则，不增加柔边或额外装饰。滑块原生位置连续为 0–100，映射到模型目录实际支持的离散档位，仅到 100 时选择最高档。动画不逐帧驱动 React 状态，仅在面板打开、控件启用且页面可见时运行；减少动态效果偏好使用相同着色器的静态画面，关闭面板释放动画、GPU 资源、尺寸观察器与监听器。原生 range 负责鼠标拖动、触屏、方向键及 Home／End，打开聚焦滑块，Escape 和 Tab 退出且不困住焦点。

切换具体模型使用该模型默认值，同一模型重选保留有效强度。Auto 同样显示推理强度入口，使用 low／medium／high／xhigh／max 五档、默认 medium，独立保存在 `autoRules.reasoningEffort`；Auto 负责自动选模型，用户仍可指定推理偏好。该偏好在切换具体模型或 Agent 后保留，修改候选池、全选或重置候选池不重置推理强度；目录尚未加载或不可用时仍可调整。Agent 及不支持离散强度调节的具体模型不显示该入口。`execution.reasoningEffort` 继续属于具体模型，两种模式的强度均进入提交快照、编辑恢复及会话上下文摘要。当前尚不产生模型调用；接入真实路由时须依据所选模型能力处理强度偏好，不把 Auto 偏好视为每个候选模型都支持同名档位。输入区宽度不超过 420 px 时，模型、推理和模式入口使用可换行的底栏左区，语音与发送移到下一行，保证模型名称可读。

模型悬停展示列表左侧信息卡，默认宽 400 px，与整个模型列表顶端对齐，不随悬停行上下跳动。菜单预留左侧空间；窗口变窄时按可用空间收紧卡宽，卡片超出下边界时整体上移并约束内容高度。信息卡保留在共享 Radix 菜单的焦点域内，鼠标穿过两者间隙不会闪退，键盘进入详情后不因鼠标移出收起；窄于 760 px 时详情保持在视口内，通过明确的返回入口、Escape 或外部关闭返回列表。触屏点击先查看资料，详情中“使用此模型”完成选择；桌面点击或键盘 Enter 可直接选择，左方向键进入详情。Escape 先关闭详情并恢复搜索焦点，再次 Escape 关闭列表并恢复入口焦点。

信息卡以模型简介开头，移除重复标题。能力测评、上下文长度、能力和价格使用紧凑分区及细小颜色标记，折叠箭头使用实心三角。能力测评固定为智能、Agentic、写作、设计、速度、价格六维雷达，常态背景透明、单色折线与半透明填充；仅悬停时显示浅灰背景，背景比正文区宽 24 px、左右各距卡片边界 8 px，轴端直接标注分数，不再展示原始 benchmark 名称。完整六维才填充闭合区域，不支持的维度显示“—”且不连接经过该轴的线段。支持维度必须有分数，真实来源缺失时由服务端目录明确保存 mock。删除图下归一化说明、评分来源及链接；每轴原生提示和无障碍描述保留真实／mock 标记、原始测量、配置与转换方法；数据定义和限制只在模型资料目录文档中维护。上下文长度常显，最大输出通过数值提示和无障碍文本提供。测评、能力和价格默认全部展开，手动折叠后切换模型保留本次偏好。能力展开使用单色线性图标、左侧名称及右侧完整支持说明，覆盖真实视觉识别、工具调用、推理、生图与视频生成能力，不添加未核实的联网支持。价格展开为输入、输出、缓存读取、缓存写入四行，使用上箭头、下箭头、环形虚线箭头和等权重中灰数值，单位直接随数值显示。价格收纳按缓存读取、输入、输出排列紧凑数值，保留真实 USD 币种。能力折叠后显示对应彩色图标；能力和价格行使用 450 字重与较深中灰，分区标题使用 500 字重。信息卡在四行价格后结束，价格条件和来源元数据保留在服务端目录中。折叠标题背景左右各保留 8 px 内边距，仅提供统一 hover 与键盘反馈。搜索支持中文输入、空结果和向下键进入列表。

本地环境菜单宽 232 px，包含新建工作树开关、分支与环境子菜单，不显示底部草稿说明及其分隔线。首页当前未接入项目仓库和执行环境绑定，分支显示“未绑定仓库”，环境显示“无环境”并可进入真实本机 Agent 设置。工作树开关只记录当前对话草稿的执行偏好，保留到提交、编辑与会话上下文摘要，不宣称已创建目录或切换分支；缺少项目时明确提示先选择项目。

输入区加号打开可搜索的功能菜单，沿用共享 chat-picker／Radix 浮层、菜单反馈与键盘导航。默认宽 304 px、32 px 行高和搜索栏、12 px 圆角、5 px 内边距，使用共享 12 px 字体与 16 px 线性图标，以及共享菜单描边和投影，按可用视口限制宽高并滚动；窄屏将模式说明换到第二行。上组为计划、调试、多任务、目标（Goal），分别配青、粉、紫、绿线性图标；目标说明为“设置要持续追求的目标”。下组为文件、skills、MCP、plugins、prompts，skills／plugins／prompts 及相关搜索、添加入口统一小写；模型仍由工具栏独立入口选择，文本和图片使用原生粘贴。搜索按名称、说明及英文模式标识过滤，空结果有明确提示；展开自动聚焦搜索，向下键进入结果，Escape 回到加号入口。每级菜单使用共享单行高亮契约：新的 hover 或键盘目标优先于旧展开态与已选项，底色立即切换，避免两个条目同时激活。菜单间切换在原菜单完成关闭后执行，避免焦点域重叠。

skills、MCP、plugins、prompts 点击或悬停展开独立二级菜单，使用 284 px 宽的紧凑面板、32 px 单行条目、9 px 圆角、共享菜单描边与接触投影；二级菜单与一级菜单顶边及搜索栏对齐，面板外框之间保留 6 px 间距，按可用视口碰撞调整。共享 ScrollArea 横向铺满二级菜单内框，滚动轨道贴右侧，滑块距外框 4 px；留白放在正文视口内，不将滚动轨道随正文向内推。顶栏提供搜索、分类快捷筛选及添加入口；搜索 placeholder 继承共享 muted 颜色，分类按钮使用横向调节图标。分类使用稳定标识，名称按语言投影。新建、筛选、配置与跳转图标使用加粗线条及正文次级墨色；市场跳转使用带方框的外链图标。

## 会话范围

首页尚无统一的任务持久化与 Agent 下发用例。本次页面展示提交内容、附件与所选上下文，并明确标识界面预览；不调用模型、不虚构分析结论、不把首页提交写入项目交付或知识库业务表。可补充消息、复制、编辑及返回初始页；主导航的“新对话”开始一份新的页面状态。刷新或离开页面不保留预览会话，文件内容也不上传。

视频中的 Google Drive / Google Docs / Dropbox 依赖原产品真实连接能力；Fouc 未建立同样的文件导入协议，因此菜单提供真实可用的本地文件入口，输入框保留原生剪贴板粘贴，不添加无效的第三方导入项。合同专属建议与结果文案改为 Fouc 通用任务文案；现有双语能力保留，用户输入和文件名不随语言切换翻译。

## 组件边界

`features/home/chat` 拥有页面、输入卡、附件、上下文选择、语音生命周期与会话呈现。skills 内置目录与默认启用配置归 features/skills，四类资源目录、插件快捷项定义及本次会话新增草稿归 features/community；首页只组合选择与任务引用，设置页只呈现配置。项目、知识库及模型／Agent 选择统一复用 `chat-picker` 的浮层、搜索框、菜单项与样式令牌，材质、字体、行高、圆角、分隔线、选中反馈和键盘处理只有一份定义；各选择器仅管理各自的筛选与上下文变更。首页入口注入统一语言层的翻译函数；shell 只负责组合页面与新对话入口重置。黑白灰强调与全局按钮、菜单、通知状态沿用共享控件；截图、视频帧和一次性比较结果不作为长期设计文档存储。
