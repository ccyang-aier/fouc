# Fouc New Conversation

新对话主页面保留 Fouc 原有导航壳，以紧凑上下文工具栏、输入卡和模型／Agent 选择菜单组织任务入口。输入卡与附件交互沿用 `opensource/dribbble/produtc-design-02.mp4` 的正向交互参考；上下文工具栏和执行选择菜单以当前用户提供的静态截图为视觉依据。

## 页面与状态

初始页采用主题面板背景、左对齐衬线问候、轻描边圆角输入卡、底部附件及模型／Agent 入口、右侧麦克风及深色语音按钮。附件、模型、麦克风和发送按钮统一使用 `--chat-control-border` 浅描边（全局控件描边与面板按 40% / 60% 混合），发送按钮保持深底。输入卡顶部为全宽 40 px 浅灰上下文工具栏，项目和知识库位于左侧，右侧齿轮展开本地环境菜单；删除深度研究、部署 Agent 和更多建议动作。输入区最小高度 86 px、底部操作按钮 30 px，保持输入卡全宽。附件菜单在入口下方展开；真实文件显示类型、文件名、大小和红色移除操作。文件卡进入约 240 ms，输入文字后语音图标切换为朝右上 45 度的实心纸飞机约 170 ms，提交后输入区移到会话底部约 480 ms。工具入口悬停不添加底色，仅将右侧小箭头向右移动 3 px；减少动态效果偏好关闭这些动效。

项目选择来自 `features/project` 的真实目录，菜单提供搜索、当前选择、新建项目和不在项目中工作；新建复用项目资源用例，名称输入与真实保存状态在菜单内完成。已选项目及无项目状态使用右侧勾号，底色仅表示当前鼠标或键盘目标，不能同时把已选项画成 hover。取消项目后入口明确显示“不在项目中工作”，并通过 AppAlert 反馈。选择只影响本次对话上下文，不更改项目授权、文档归属或资源权限。项目与知识库弹窗共用 224 px 宽、12 px 圆角、12 px 正文、28 px 行高和 36 px 搜索栏，在工具栏上方展开。知识库菜单提供同样的搜索栏、资源图标、右侧勾选、空结果和不使用知识库入口；仍保持首页知识上下文演示的边界，不冒充真实知识库目录或 ACL。

模型／Agent 共用一个可搜索菜单，新对话默认使用模型 Auto 模式；打开菜单时显示当前选择所属列表，并将已选项滚入视口。右上角以大脑和 Agent 头盔图标切换列表；切换列表不直接更改选择，点击列表项才保存执行类型；具体模型和 Agent 同时保存唯一 ID 与名称快照，入口和提交后的上下文摘要显示对应名称。打开时以共享菜单背景条标识已选项；鼠标或键盘进入其他行后，背景条只跟随当前交互行，选择勾号继续保留。Auto 是独立的自动选择意图，不伪装成服务端目录中的具体模型；实际自动路由随统一任务下发用例接入。Auto 位于模型列表顶部，与搜索框留出 16 px 间隔，使用紫色圆形容器和四角星图标，即使目录加载失败也可选择；具体模型按 OpenAI、Anthropic、Google、DeepSeek 分区，仅显示有结果的供应商。搜索同时筛选模型名称、供应商和 Auto，空结果不保留空分区。

Auto 悬停、键盘方向键或触屏点击复用模型左侧资料浮层，采用独立 300 px 宽的紧凑面板，默认约 128 px 高：22 px 图标与 14 px 名称、简短说明、一行候选模型配置入口。默认不展示模型长列表、全选工具栏或底部说明；点击入口后展开 28 px 单行候选列表，删除重复供应商副标题，收起后显示全部模型或已选数量。候选项来自服务端模型目录，支持勾选、全选、重置和必要的异常反馈，至少保留一个当前目录模型。`autoRules.modelIds = null` 表示全部目录模型，显式数组限定候选模型 ID；修改立即记录当前对话草稿，提交和编辑保留规则，切换具体模型或 Agent 不丢失该偏好。规则不代表已获得模型执行权限，也不产生真实调用。

参考截图用于还原比例、材质和布局，不将截图的物理像素直接作为 CSS 尺寸。模型弹窗为 324 px 宽、36 px 独立描边搜索框、13 px 正文、34 px 行高、18 px 品牌图标，列表最高 340 px；搜索焦点只强化描边，不增加阴影或 ring。弹窗沿用轻边界、层次投影和浮起的白色分段选中面。列表和资料卡滚动条贴近浮层右边框，正文独立留白；窄屏详情覆盖列表时，列表滚动条留在自己的绘制层内。模型列展示厂商图标和名称，右侧固定为选择勾号、已核实上下文长度，长度始终最靠右；勾号预留位置，与数值垂直居中。勾号保持深墨色、图像模型图标保持绿色，均不随悬停或选择改变颜色。删除没有数据依据的示例能力条、倍率和新模型标记。

模型元数据由业务服务公开目录提供，所有权和数据规则见[模型资料目录](../agents/fouc-model-catalog-design.md)。展开菜单时读取，选择模型后保留查询缓存；多个输入区去重请求，缓存有效期 15 分钟。首次加载、请求失败重试、空目录与无搜索结果有各自反馈，服务错误不能静默替换为示例目录。Nova / Codey / Sage 仍是演示 Agent，不伪造其实际安装或可用能力。

模型悬停展示列表左侧信息卡，默认宽 400 px，与整个模型列表顶端对齐，不随悬停行上下跳动。菜单预留左侧空间；窗口变窄时按可用空间收紧卡宽，卡片超出下边界时整体上移并约束内容高度。信息卡保留在共享 Radix 菜单的焦点域内，鼠标穿过两者间隙不会闪退，键盘进入详情后不因鼠标移出收起；窄于 760 px 时详情保持在视口内，通过明确的返回入口、Escape 或外部关闭返回列表。触屏点击先查看资料，详情中“使用此模型”完成选择；桌面点击或键盘 Enter 可直接选择，左方向键进入详情。Escape 先关闭详情并恢复搜索焦点，再次 Escape 关闭列表并恢复入口焦点。

信息卡以模型简介开头，移除重复标题。能力测评、上下文长度、能力和价格使用紧凑分区及细小颜色标记，折叠箭头使用实心三角。雷达图直接在每个轴端显示真实测试名称与百分比成绩，不使用数字编号，也不再另放重复图例；只有至少三个原始百分比成绩才绘制同模型雷达，少于三项时保留无编号成绩列表，不编造轴或综合分。上下文长度常显，最大输出通过该数值提示和无障碍文本提供。测评、能力和价格默认全部展开，手动折叠后切换模型保留本次偏好。能力展开按参考图使用单色眼睛、扳手、原子等线性图标，左侧名称、右侧完整支持说明，保留真实图像生成能力，不因参考图添加未核实的联网搜索支持。价格展开为输入、输出、缓存读取、缓存写入四行，使用上箭头、下箭头、环形虚线箭头和等权重中灰数值，输入／输出图标按文字视觉中心微调；无彩色图标底块、加重数字列、缓存分隔线或独立单位标题，单位直接随每行数值显示。价格收纳按缓存读取、输入、输出排列黑色图标和紧凑数值，保留真实 USD 币种，不将其改写成参考产品积分。能力折叠后显示对应彩色图标。能力和价格行使用 450 字重与较深中灰，分区标题使用 500 字重。信息卡在四行价格后结束，不显示价格备注、来源与核实日期底栏；价格条件和来源元数据保留在服务端目录中。折叠标题背景左右各保留 8 px 内边距，分区标题不因 aria-expanded 持续铺灰底，仍提供统一 hover 与键盘反馈。搜索支持中文输入、空结果和向下键进入列表。

本地环境菜单宽 232 px，包含新建工作树开关、分支与环境子菜单，不显示底部草稿说明及其分隔线。首页当前未接入项目仓库和执行环境绑定，分支显示“未绑定仓库”，环境显示“无环境”并可进入真实本机 Agent 设置。工作树开关只记录当前对话草稿的执行偏好，保留到提交、编辑与会话上下文摘要，不宣称已创建目录或切换分支；缺少项目时明确提示先选择项目。

Enter 发送，Shift Enter 换行，Ctrl / Cmd Enter 也可发送；中文输入法组合输入不触发提交。空内容显示校验反馈并保留焦点。附件支持文件选择、剪贴板图片、拖放、去重和单独移除；图片预览使用可释放的本地对象 URL。删除附件不删除磁盘文件。输入焦点只改变卡片边框，不增加阴影或 ring。

语音输入使用浏览器实际支持的 SpeechRecognition；不支持、权限拒绝和未识别到语音通过全局 AppAlert 反馈，不显示伪造的识别结果。离开组件释放识别会话。

## 会话范围

首页尚无统一的任务持久化与 Agent 下发用例。本次页面展示提交内容、附件与所选上下文，并明确标识界面预览；不调用模型、不虚构分析结论、不把首页提交写入项目交付或知识库业务表。可补充消息、复制、编辑及返回初始页；主导航的“新对话”开始一份新的页面状态。刷新或离开页面不保留预览会话，文件内容也不上传。

视频中的 Google Drive / Google Docs / Dropbox 依赖原产品真实连接能力；Fouc 未建立同样的文件导入协议，因此菜单提供真实可用的本地文件和剪贴板入口，不添加无效的第三方导入项。合同专属建议与结果文案改为 Fouc 通用任务文案；现有双语能力保留，用户输入和文件名不随语言切换翻译。

## 组件边界

`features/home/chat` 拥有页面、输入卡、附件、上下文选择、语音生命周期与会话呈现。项目、知识库及模型／Agent 选择统一复用 `chat-picker` 的浮层、搜索框、菜单项与样式令牌，材质、字体、行高、圆角、分隔线、选中反馈和键盘处理只有一份定义；各选择器仅管理各自的筛选与上下文变更。首页入口注入统一语言层的翻译函数；shell 只负责组合页面与新对话入口重置。主题色与全局按钮、菜单、通知状态沿用共享控件；截图、视频帧和一次性比较结果不作为长期设计文档存储。
