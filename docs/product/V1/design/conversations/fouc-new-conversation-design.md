# Fouc New Conversation

新对话主页面保留 Fouc 原有导航壳，以紧凑上下文工具栏、输入卡和模型／Agent 选择菜单组织任务入口。输入卡与附件交互沿用 `opensource/dribbble/produtc-design-02.mp4` 的正向交互参考；上下文工具栏和执行选择菜单以当前用户提供的静态截图为视觉依据。

## 页面与状态

初始页采用主题面板背景、左对齐衬线问候、轻描边圆角输入卡、底部附件及模型／Agent 入口、右侧麦克风及深色语音按钮。输入卡顶部为全宽 40 px 浅灰上下文工具栏，项目和知识库位于左侧，右侧设置打开现有 Agent 设置；删除深度研究、部署 Agent 和更多建议动作。输入区最小高度 86 px、底部操作按钮 30 px，保持输入卡全宽。附件菜单在入口下方展开；真实文件显示类型、文件名、大小和红色移除操作。文件卡进入约 240 ms，输入文字后语音图标切换为上箭头约 170 ms，提交后输入区移到会话底部约 480 ms。减少动态效果偏好关闭这些动效。

项目选择来自 `features/project` 的真实目录，菜单提供搜索、当前选择、新建项目和不在项目中工作；新建复用项目资源用例，名称输入与真实保存状态在菜单内完成。选择只影响本次对话上下文，不更改项目授权、文档归属或资源权限。项目弹窗宽 264 px、16 px 圆角、14 px 正文和 30 px 行高，在工具栏上方展开。知识库开关仍是首页上下文演示，不冒充真实知识库 ACL。

模型／Agent 共用一个可搜索菜单，初次打开显示模型列表，右上角以大脑和 Agent 头盔图标切换并记住当前列表；切换列表不直接更改选择，点击列表项才保存执行类型及唯一 ID，入口和提交后的上下文摘要显示对应名称。参考截图用于还原比例、材质和布局，不将截图的物理像素直接作为 CSS 尺寸。弹窗沿用产品的正常菜单尺度：336 px 宽、50 px 搜索栏、14 px 正文、38 px 行高、20 px 品牌图标与 24×4 px 能力条，列表最高 380 px；使用轻边界、内侧高光、层次投影和浮起的白色分段选中面。菜单优先在入口上方就近展开，空间不足时由共享浮层自动调整方向，并按视口约束高度与宽度。菜单使用厂商 Logo、圆形品牌底色、推理级别、新模型标签、双能力条和倍率布局。模型目录及指标按参考图提供界面预览，示例说明通过菜单无障碍描述及指标悬停提示提供；不代表可用模型、真实价格或服务能力。Nova / Codey / Sage 同样属于演示 Agent。搜索支持中文输入、无结果状态和向下键进入列表；选择、Escape、外部点击沿用共享菜单的关闭和回焦行为。

Enter 发送，Shift Enter 换行，Ctrl / Cmd Enter 也可发送；中文输入法组合输入不触发提交。空内容显示校验反馈并保留焦点。附件支持文件选择、剪贴板图片、拖放、去重和单独移除；图片预览使用可释放的本地对象 URL。删除附件不删除磁盘文件。输入焦点只改变卡片边框，不增加阴影或 ring。

语音输入使用浏览器实际支持的 SpeechRecognition；不支持、权限拒绝和未识别到语音通过全局 AppAlert 反馈，不显示伪造的识别结果。离开组件释放识别会话。

## 会话范围

首页尚无统一的任务持久化与 Agent 下发用例。本次页面展示提交内容、附件与所选上下文，并明确标识界面预览；不调用模型、不虚构分析结论、不把首页提交写入项目交付或知识库业务表。可补充消息、复制、编辑及返回初始页；主导航的“新对话”开始一份新的页面状态。刷新或离开页面不保留预览会话，文件内容也不上传。

视频中的 Google Drive / Google Docs / Dropbox 依赖原产品真实连接能力；Fouc 未建立同样的文件导入协议，因此菜单提供真实可用的本地文件和剪贴板入口，不添加无效的第三方导入项。合同专属建议与结果文案改为 Fouc 通用任务文案；现有双语能力保留，用户输入和文件名不随语言切换翻译。

## 组件边界

`features/home/chat` 拥有页面、输入卡、附件、上下文选择、语音生命周期与会话呈现。首页入口注入统一语言层的翻译函数；shell 只负责组合页面与新对话入口重置。主题色与全局按钮、菜单、通知状态沿用共享控件；截图、视频帧和一次性比较结果不作为长期设计文档存储。
