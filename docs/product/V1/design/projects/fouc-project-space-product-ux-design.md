# Fouc 项目工作台与单侧栏设计

## 产品与作用域

一个 Fouc 管理界面承载一个当前项目的完整工作台。项目是业务隔离域，以真实 `projectId` 及项目成员授权管理；不增加 workspace 实体、默认空间或嵌套项目授权层。顶部项目选择器是唯一项目切换入口，不再提供外层项目目录或项目内第二套应用导航。

项目内的任务、资产、成员管理、聊天、最近对话与个人选择状态默认属于当前项目。切换项目立即隔离内容、输入、弹窗草稿和最近记录；账户切换同时改变私有缓存范围。前端状态隔离不能代替服务端对真实项目及操作的权限校验。

社区与连接器目录是全项目可发现的基础设施；全局目录不代表共享凭据或获得连接执行权限。本机 Agent 的发现、安装与运行能力属于真实设备，Agents 页面复用该设备能力；展示同一设备的 Agent 不代表它获得任何项目资源权限。

知识库保持独立、多实例资源，拥有文件夹与文档，不被项目包含。知识库 owner 配置允许发现该库的项目集合；当前项目成员资格、项目开放范围、库成员与页面 ACL 共同限制访问。关联或引用都不隐式授予文档权限。具体规则见[知识库设计](../knowledgebase/fouc-knowledgebase-product-design.md)。

应用始终复用同一菜单侧栏和系统栏。知识库文件夹树、社区资源分类及连接器对象树属于当前工作面的资源浏览，不再建立第二套项目管理界面；进入这些服务不自动收起主导航。主侧栏默认宽度 272px，可在 204～360px 间拖动，主动收起后为 52px 图标轨道，并隐藏整个项目切换区域。主体内容独立滚动。社区、连接器、知识库固定在账户栏上方，不显示“服务”分组标题。

外壳以统一浅灰材质连接侧栏与 44px 紧凑顶栏，不显示品牌 Logo、独立品牌行或贯穿顶栏的竖向分隔线。侧栏顶行左侧为项目选择器，右侧为收纳按钮；收起后顶行只保留展开图标，导航列表与顶行之间留出 8px 间距。主工作面从顶栏下方开始，四角均为 16px 圆角，右侧贴齐应用视窗、底部留出 4px，使用单层浅描边。内部知识库、社区及连接器的树、工具栏和滚动区域仍归各页面所有，弹层挂到既有外壳宿主，避免被工作面圆角裁切。

内容上方的顶栏左侧依次是后退、前进，中央是打开的页面页签，右侧是全局搜索、通知、任务及原有窗口控制。全局搜索默认仅显示图标，点击或 Ctrl / ⌘ K 打开搜索面板，保留页面与功能搜索、无结果状态、方向键选择、回车导航、Escape 关闭及回焦；不在顶栏保留常驻输入框。主页面切换写入浏览器历史，无可用记录时禁用对应箭头，重复进入当前页面不叠加记录，后退后进入另一页会舍弃前进分支。设置的打开、分区选择和关闭属于当前页面的覆盖层，不新增页签或主页面记录。导航历史仅作用于当前身份、来源与项目会话，切换范围重新开始，不借助历史恢复已离开的项目或扩大资源访问权限。

侧栏菜单、搜索及页面内导航共用页签入口：第一次打开创建页签，再次进入切换到已有页签；当前存在同一页面的多个副本时，优先保留当前匹配页，再选择已有页面。页签显示与侧栏相同的图标、名称和独立关闭按钮；当前页以轻浅的中性底色、柔和描边和适中加粗标题与非当前页区分，避免大面积深灰。选择面以弹簧位移衔接，新建和关闭采用轻微缩放与淡入淡出，页面切换以约 180ms 轻淡入衔接。超出宽度时横向滚动并显示左右浏览按钮，指针位于页签区时纵向鼠标滚轮转为水平浏览，保留原生横向触控板手势及 Ctrl 滚轮缩放；手动浏览不改变当前页或自动拉回。打开、切换及重新选择当前菜单页时，当前页及关闭按钮自动进入可见范围；键盘左右箭头、Home／End 切换，Delete 关闭当前页签。关闭非当前页不切换；关闭当前页选择左邻，首项选择右邻，关闭最后一个页签打开新的空白对话页。关闭动作只释放页面，不删除其业务资源或对话历史。

纵向滚轮按时间阻尼平滑追随累计目标，松手后短暂滑行，反向输入从当前位置立即转向，边界内收敛且不回弹；原生横向手势继续由浏览器处理。手动浏览会取消待执行或进行中的自动定位，尺寸变化、后台置顶／关闭／重新加载及菜单回焦均不拉回激活页。明确的打开、切换、重选和新建操作发出独立定位请求，停止惯性后定位目标页；请求只属于当前界面会话，不进入页面恢复数据。

新增及关闭一次确定页签布局宽度，退出项脱离布局并裁切在最终内容范围内；只对同一组页签的排序变化执行位置插值，避免浏览器收缩滚动范围与布局动画互相补偿造成末尾反向位移。自动定位统一合并到溢出按钮布局稳定后，按最终布局坐标计算最小滚动，不读取动画中的矩形或在动画结束时重复校正。

页签可沿水平方向拖拽排序：超过轻微移动阈值才开始拖动，拖动项跟随指针，相邻页签以弹簧位移让位，释放后吸附回新位置，靠近滚动边缘时继续浏览。拖动只调整顺序，不重建页面或改写其位置参数。置顶页签排在左侧并显示图钉，允许在置顶组内调整顺序，普通页签不能拖到置顶组前；置顶、取消置顶不切换当前页面，置顶状态参与本机恢复。

页签右键或键盘菜单键／Shift F10 打开统一操作菜单，提供置顶／取消置顶、重新加载、复制标签页、关闭、关闭其它标签页和关闭全部标签页；操作对象是打开菜单的页签。重新加载只重建目标页面并恢复可保存草稿、筛选和滚动位置，不刷新应用或影响其他页面。复制在原页后方新建独立页面实例，置顶页的副本进入普通页签区；复制其位置参数及可恢复界面状态，后续草稿与筛选独立。同一资源的业务内容仍由原功能所有者共享，对话副本读取同一消息历史，避免互相覆盖。批量关闭包含置顶页签，无其他页时禁用关闭其它操作；保留页面的实例与状态不变，当前页被移除时选择最近的保留左邻，没有左邻则选择首个保留页；关闭全部创建新的空白对话页。

最后一个页签右侧始终提供新建图标，页签较少时紧跟末项，溢出时保留在滚动区域右侧可见位置。单击创建独立空白新对话页，不复用已有草稿；右键或键盘菜单键打开页面创建菜单，当前仅提供新对话，通过统一页面选项列表预留后续扩展。副本拥有独立页签标识，参与排序、恢复和浏览器历史，不能因页面名称或目标相同被去重吞并。

打开的页面在当前应用会话中保留实际页面实例、输入草稿、筛选、列表样式、滚动位置以及编辑器和协作连接；首次进入才创建，切换时隐藏并隔离键盘交互，关闭页签或切换身份／项目才释放。后台页暂停面向整页的快捷键，不抢前台焦点；原生模态表单在浏览器历史离开页面时关闭，避免隐藏模态继续阻塞窗口。页签顺序、激活页和可恢复页面状态保存到当前设备的 IndexedDB，按账户身份、项目来源与项目 ID 隔离；刷新、重新打开和切回项目时恢复，项目及账户切换只释放运行中的页面，不删除其恢复记录。恢复等待身份确认、项目选择及本机记录加载完成，避免访客记录提前改写账户的启动地址。首次显式页面／文档／工作台链接优先于上次激活页，启动意图只消费一次；普通启动入口恢复上次激活页，后续身份切换恢复各自记录。失效的对话页签被移除，资源页继续经过原有权限与存在性检查。

页面状态由各功能声明保存：对话草稿、附件、模式与上下文，社区与连接器的筛选／排序／视图及详情选择，知识库浏览位置、文件夹／文档选择、侧栏及文档列表筛选。File、Blob 和 Date 使用结构化克隆保存，避免丢失文件内容或日期类型；文档正文仍由知识库已有文档存储与协作链路负责，不另建正文副本。工作台、对话、社区、连接器、文档列表与富文本编辑器的主滚动区使用稳定标识恢复，等待异步内容具备足够高度，新交互会取消尚未完成的自动恢复，避免跳动。临时模态及未接入的嵌入式视图不承诺跨进程恢复；保存失败通过 AppAlert 提示，当前会话仍可操作。关闭页签仅清理其页面恢复状态，不删除预览对话或业务资源。

非激活页签保持浅灰容器背景，深浅主题都保留与当前页的视觉层级。页签操作菜单采用共享菜单材质、统一图标、圆角及紧凑间距，不添加头部、目标名称或数量；前三项页面操作与后三项关闭操作使用内缩分隔线分组。

对话按真实预览 ID 打开独立页签，侧栏重复打开同一对话切换到已有页面，主动复制可以保留多个视图。新对话首次发送后将当前草稿页转为该对话，保留输入组件实例，名称随对话重命名更新；之后点击侧栏新对话打开或切换空白草稿页。删除对话同时关闭其所有副本页签，删除当前对话回到空白对话页。未绑定资源的频道继续使用既有整理与编辑入口，不伪造频道页面。

主导航图标默认使用深灰轮廓与浅灰局部填充的半实心双色风格，选中时保持图形和灰度，由共享行背景、描边和文字反馈表达当前项。菜单行激活保持浅灰 `#efefef` 平面底条，hover 使用更浅的 `#f3f3f3`，均保留轻描边，不使用白底浮起阴影。普通鼠标焦点不维持高亮；只有当前页面使用激活底色，键盘焦点与行内菜单展开复用较轻的交互反馈。保持 Fouc 现有浅深主题与字体，主导航不引入额外彩色背景或另一套样式体系。

新对话保留原有气泡图标，与工作台等主菜单项使用相同行高与行距。智能体入口随界面语言显示“智能体”或“Agents”，其下方使用两侧留白的分隔线。置顶、频道、最近采用带折叠箭头的分区行，标题 12px，内容向内缩进，频道、最近标题右侧保留更多和新建入口，置顶标题只提供折叠。标题整行只在 hover 时显示浅灰背景，鼠标离开立即清除，不因展开状态、菜单打开或鼠标点击后的焦点保留底条；键盘定位只显示边框。条目背景左右边界与主菜单对齐，12px 层级缩进放在条目内部，保留图标和文字的视觉缩进。

底部身份与操作使用一行布局：左侧是浅灰底的头像与用户名入口，hover 时加深至 `#e4e4e4`，保留设备状态角标与账户菜单；右侧依次是主题和设置图标。主题按钮采用基于 Magic UI 的共享 `AnimatedThemeToggler`，点击后以按钮中心为起点，在 400ms 内圆形扩散至整页，直接切换浅色与深色；复用已有外观偏好并持久化，与设置页同步。跟随系统仍在设置页选择，按钮图标随系统实际明暗状态更新。设置图标打开现有设置弹窗。收起后底栏仅保留居中的账户头像及提示，隐藏主题与设置。

频道条目左侧使用线性的 `#` 图标，支持新建、重命名、名称排序和确认删除，作为当前设备上的项目整理标记，按完整身份、项目来源与 ID 保存，暂不绑定资源或承诺跨设备同步。频道上方按需显示统一置顶分区，聚合当前项目已置顶的频道和对话；没有置顶内容时隐藏整个分区。置顶项从原频道／最近列表移入该区，不重复显示；取消置顶后回到对应列表，频道保留名称排序，对话按更新时间排列，最近仅取未置顶对话的前六条，置顶对话不占最近名额。所有条目在 hover、键盘可见焦点或行内菜单打开时才显示操作图标，顺序固定为左侧置顶／取消置顶、最右侧更多；已置顶条目同样不常驻显示操作图标。置顶与取消成功通过共享 AppAlert 提示。行内更多菜单提供重命名和红色删除项，删除需独立确认。最近分区的新建入口创建对话，分区更多菜单可进入全部项目对话。切换项目关闭未完成的条目弹窗，保存失败保留原有频道。

## 顶部项目切换

侧栏顶行的大半部分为紧凑项目入口：左侧 24px 圆角流体染料图标、可截断项目名、右侧双向切换标识。图标维护有连续历史状态的二维速度场与四路颜料浓度，通过压力投影与平流使不同大小的色团缓慢推挤、卷入和交融；误差校正与局部扩散共同保持自然的混色边界，柔和密度明暗表现颜料厚度。流速按实际 24px 尺寸校准，持续观察几秒即可看见色团位移与卷曲；采用小步推进保持连续自然的液态感。容器始终填满，新流场使用随机初始分布，刷新页面不重播固定开场；项目入口与列表共用项目流场，切换配色保持流动连续，六个配色预览各自维护独立流场与相位。菜单关闭或离开视口时停止推进与绘制，重新显示从保留状态继续；会话内最多保留 24 个未使用流场，超出后按最久未使用顺序释放，不保留 Canvas 或动画调度。项目 ID 只决定稳定默认搭配，切换菜单中的“图标配色”提供六组可切换染料，偏好按身份、来源与项目保存在当前设备，不改变项目权限或主题。项目入口沿用外壳底色，轻量悬停反馈与图标建立当前项目身份；收起时隐藏整个项目切换区域，展开后恢复入口。

弹窗顶层搜索真实可访问项目，列表显示项目名称、真实本机／团队来源及当前选择勾号。搜索无结果、加载和服务失败分别反馈；底部提供新建、当前项目重命名及删除。没有项目时展示选择／创建引导，不伪造默认项目，不回到已删除的外层项目目录。

创建与重命名使用紧凑独立表单，空白名称禁止提交，提交中显示共享三点反馈，失败保留输入；团队项目调用真实服务端用例，本机项目由浏览器明确保存。删除保留危险色及确认，只有真实成功后更新目录和当前选择；服务端继续校验项目管理权限。切换后进入目标项目工作台，失效选择只能回落到真实可访问项目。

## 页面边界

| 页面 | 本次内容 |
| --- | --- |
| 工作台 | 迁移现有项目 Dashboard 首页及其必要交互 |
| 任务 | 项目隔离的多任务看板、Kanban、细粒度任务与看板成员授权 |
| 成员、资产 | 保留独立入口及清晰空状态，暂不迁移原分区 |
| 聊天 | 当前项目的会话列表、创建新对话与打开已有对话 |
| 智能体 / Agents | 真实本机 Agent 发现、登记、状态与管理能力，不在侧栏展开二级列表 |
| 服务 | 社区和连接器全局目录，知识库按当前项目开放范围和既有授权查询 |
| 频道 | 当前项目频道区域，尚无记录时显示空状态，不渲染虚构数量或不可用操作 |
| 最近 | 当前项目最近对话的投影，点击恢复该对话 |

旧项目目录、旧项目管理侧栏，以及旧工作台的 My Task、Inbox、Reporting、Portfolio、Accounts、Goals 等独立分区与专属依赖清除。自动化菜单、页面、演示数据和唯一依赖从产品移除，不以隐藏路由或兼容入口保留。

## 工作台首页

首页延续用户指定视频 `opensource/dribbble/produtc-design-01.mp4` 的内容布局，去掉视频页面自身的身份侧栏、导航、顶部工具栏及重复字体系统。快捷创建、统计、活动时间线、团队、今日项目卡、会议、里程碑与动态在统一 Fouc 工作面内呈现。通用图标复用 Fouc 默认双色图标，主题与字体继承系统。

统计与“查看全部”入口导航至主菜单对应页面，不重新展开旧分区。创建账单、提案、合同、表单，以及首页卡片详情、任务、会议、协作者和里程碑的必要弹窗保留；取消不保存、提交保留真实反馈、关闭恢复焦点。

工作台参考人物、项目卡、任务、统计与活动仍是本机界面交互样例。它们按身份、项目来源和真实项目 ID 独立保存，不写入服务端项目业务表，不形成真实团队成员资格，与任务菜单的真实看板数据独立；资产页面仍未接入业务持久化。“今日项目”中的样例卡是首页组合内容，不是额外项目隔离域。

活动时间线按样例任务排期和会议生成，支持日／周／月／年窗口及详情；里程碑支持目标和历史编辑、范围切换与导出。首页统计来自当前作用域记录，不使用隐藏固定基数。文档就绪、完成或会议导出只表示本机记录状态，不表示发送发票、签署合同或发布外部表单。

任务、文档、会议链接携带完整作用域，只能在相同身份、来源、项目以及该设备已有记录中恢复；不同作用域的同名样例不互相打开。用户编辑的正文、姓名、文件名和协议标识不随语言切换被覆盖。参考附件缺少真实文件时仅展示来源说明，不伪造下载内容。

## 项目任务看板

任务菜单面向真实服务端项目中的团队需求与任务跟踪。一个项目可创建多个独立看板，用于个人待办、项目交付或某项特性；不存在全局任务空间。顶部用可搜索的看板切换器收纳目录，保留新建入口；选择、搜索、筛选、排序和滚动位置进入已有按身份与项目隔离的页面恢复记录。任务正文始终从业务服务读取，界面恢复记录不代替资源授权。

任务页复用系统栏的历史前进与回退，不重复展示菜单面包屑。页头使用 16px 的紧凑看板名称，附可见性；右侧显示真实更新时间、最多三个 28px 成员头像与剩余人数，创建人另有 30px 高的黑色“邀请”按钮。头像组和邀请入口打开其下方的非模态成员浮层，保留原有成员授权、邀请范围与错误反馈，支持点击外部或 Escape 关闭及嵌套权限菜单，不遮挡或锁定整页。头像组保留成员管理的可访问名称，不展示冗余说明文字。描述在看板设置中维护，不占据独立说明行。

下一行工具栏左侧用 22px 进度环和“已完成数 / 总数 · 已完成”呈现实际进度，替代零散计数与细横线。右侧的分段视图按看板、时间线、表格、日历排列，图标均位于文字之前，最左侧看板以白色选中块强调。浅灰底座统一为 30px 高，内部选中块 24px、文字 12px、图标 16px；当前仅实现 Kanban，其余视图保留正常可读的次级颜色、禁用语义和规划提示。连续操作组依次排列负责人、筛选、双向排序箭头、闪电、搜索、更多与黑色新建分体按钮：负责人使用单图标入口并保留筛选状态；方形按钮 30px、间距 6px、线性轮廓图标 16px；新建为 96px 宽，主按钮 72px、下拉 24px，文案“新建”，不带加号。两组控件保持同一高度与垂直中心线。闪电菜单复用分配给我、逾期和清除筛选，新建下拉提供新增状态列。主页面内容菜单使用线性图标，不套用系统侧栏的半实心双色规范。搜索按需展开，筛选与非手动排序保持激活反馈。上下留白对称，窄窗口按操作组换行。浅色模式的任务画布与页头统一使用白色面板背景，列容器用浅灰背景分组，卡片保持白色。

新看板默认仅创建人可见。可见性与编辑权限独立：

| 可见性 | 可见成员 | 编辑及管理 |
| --- | --- | --- |
| 仅自己 | 当前项目中的创建人 | 创建人编辑并管理 |
| 项目可见 | 当前项目的全部成员 | 默认只读，创建人逐人授予编辑 |
| 受邀成员 | 创建人与明确加入看板的项目成员 | 新成员默认只读，可由创建人授予编辑 |

只有创建人管理看板名称、描述、可见性、成员和删除；项目 owner／admin 不绕过其他人的私有看板权限。编辑者可管理任务、状态列与评论，只读成员只能查看。受邀成员从真实项目成员中选择，不通过此功能创建账户或扩大项目成员资格。撤销项目成员资格立即失去看板访问；重新加入项目不恢复先前邀请。切换为私有时清除成员授权及失效任务分配。任务负责人仅可从当前具有看板访问权的项目成员中选择，返回数据过滤失效负责人。前端响应权限变化并重新查询目录。

本期完整实现 Kanban；分段视图按列表、时间线、看板排列，前两项不可选并提示规划中。默认列为待处理、进行中、待审核、已完成；编辑者可新增、重命名、调整语义色、设置完成标记、左右重排和删除空列。列头使用状态环、计数徽标、列操作点阵菜单和添加入口；点阵菜单沿用左右移动操作，不伪装为拖动柄。完成标记决定真实完成数，不依赖列名；非空列必须先移走任务。卡片头展示稳定任务编号、状态环与更多操作，正文使用单层描边、紧凑标签、优先级、检查清单进度、日期、评论数及真实负责人头像；不渲染虚构附件或统计。

任务包含看板内从 1 递增的只读编号（展示为 `TASK-1`）、标题、纯文本描述、优先级、多负责人、截止日期、标签和可勾选检查清单。编号在看板写事务中分配并持久化，编辑、移动和排序不改变编号，删除不回收编号；数据库以项目、看板和编号共同约束唯一性。分配函数验证当前会话与看板编辑权限，只更新内部计数，不授予编辑者修改看板设置的权限。点击卡片打开右侧详情，可保存、取消、确认放弃或删除；评论独立提交，显示真实作者与时间，作者或看板创建人可删除自己的授权范围内评论。只读时隐藏变更入口。原生弹窗包含键盘焦点、Escape、失败恢复及危险操作确认；共享下拉菜单在打开时解析当前弹层宿主，子菜单继承该宿主，避免关闭抽屉后仍挂载到失效节点。按钮使用共享三点 loading，消息复用 AppAlert。

支持同列重排、跨列拖动以及任务菜单移动，移动与排序落库。筛选与自动排序时停止手动拖排并提示恢复方法，避免隐藏任务造成不明确的位置。搜索匹配编号、标题、描述和标签；筛选覆盖负责人、优先级、标签、逾期和未来七天，排序覆盖手动、优先级、截止日期、更新时间和名称。逾期判定使用本地日历日并排除完成状态。可见页面每十五秒及重新聚焦时同步，隐藏页停止轮询；这不是多人实时协同编辑协议。

业务用例归 `backend/server/modules/tasks`，前端归 `features/tasks`，公共类型和输入约束经 `@fouc/shared/tasks` 导出。`resources` 下的看板、看板成员、状态列、任务、评论五张表使用组合外键与强制 RLS；每次读写同时验证有效身份、当前项目成员资格和看板权限。写操作在看板锁内串行并重新确认权限，排序与内容变更作为同一事务完成。当前唯一 schema 直接维护在 `current.sql`，不引入旧开发数据迁移或兼容路径。

本机项目不伪造服务端看板；该入口提示从顶部切换至服务端项目，访客可进入既有登录流程。登录、退出不迁移任务内容。首页交互样例继续独立于真实看板；本期不增加附件上传、AI 自动拆解、外部通知、项目邀请或执行调度。

## 聊天与最近记录

新对话始终继承顶部当前项目，输入卡不再提供“选择项目”或“不在项目中工作”。知识库选择读取当前项目真实可见目录，选中的 ID 与名称进入提交快照；不使用固定的“团队知识库”演示选择。

预览会话按身份、项目来源及项目 ID 保存在当前设备，项目间和账户间不能互相读取。主菜单聊天列表、侧栏最近与对话页最近记录共享同一来源，重命名同步更新各处名称和当前对话标题，不修改原始消息；继续发送或编辑消息保留名称和置顶状态。删除当前对话后返回新对话，其他会话保留。切回项目、刷新或重新打开后可恢复该项目已有预览及相关页签；附件仅在本机保存，不上传，仍不下发 Agent 或模型调用，不能将恢复后的预览呈现为真实设备执行会话。

## 授权与验证

项目选择仅定位工作台，不授予项目权限。服务端项目目录只返回本人真实成员项目，重命名和删除继续要求管理角色。服务端知识库的项目范围关联由 owner 维护，列表按当前真实项目与主体重新查询；迟到响应不能覆盖切换后的页面，库内每次操作仍检查原有成员及页面权限。

验收聚焦顶部项目切换、搜索、表单与错误反馈、单一导航、工作台首页保留交互、新页面空态、聊天与最近联动，以及身份／项目边界和知识库项目开放范围。深浅主题、键盘关闭回焦和必要窄窗口布局保持完整。开发服务常驻并刷新源码，不因本次 Web 重构构建 Tauri 客户端。
