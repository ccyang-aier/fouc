Fouc incorporates adapted DBX driver and connection Profile descriptors and
SQL dialect metadata in shared/catalog/dbx-catalog.json. The YAML dialect
descriptors were converted to JSON. The MySQL metadata lookup sequence was
adapted for the Fouc Bun sidecar.

MySQL workspace sessions, bounded array-row reads and metadata fallback are
adapted from crates/dbx-drivers/src/db/mysql.rs. Table-change plans, generated
column omission, key predicates and row guards follow
crates/dbx-sql/src/data_grid_sql.rs. Fouc uses parameter bindings and native
driver transactions in relational-save.ts; it does not load DBX runtime code.
Typed table filters, NULL-aware membership/ranges and multicolumn sorting also
follow data_grid_sql.rs and the desktop grid interaction model. Fouc compiles
validated field metadata and bound values in relational-table-query.ts.

PostgreSQL catalog discovery and bounded read-only cursors, SQLite file opening
and table_xinfo metadata, and relational query guards are behavior adaptations
of crates/dbx-drivers/src/db/{postgres.rs,sqlite.rs} and dbx-core/src/query/.
The connection/workbench layout follows apps/desktop/src/components/{connection,
layout,grid}. Fouc's corresponding implementation is independently written in
backend/device/src/database/{drivers,relational-*}, shared/src/relational.ts and
src/features/connectors/datastore/ using TypeScript, React and Node-compatible APIs.
The SQLite connector SVG is an original Fouc illustration.
SQL query tab lifecycle, navigation history, pin/order/close/reopen actions,
editor-state preservation and durable drafts adapt queryStore.ts and
lib/{app/openTabsPersistence,tabs/*}.ts. Fouc stores workspace/connection-scoped
drafts in its own SQLite repository and serializes version-checked saves through
its React controller; no DBX runtime modules are imported.
SQL metadata completion adapts QueryEditor.vue's lazy metadata and request epochs,
lib/sql/sqlCompletionLookupTarget.ts and lib/sql/semantic/tokens.ts for native
MySQL/PostgreSQL/SQLite scopes. Fouc owns the React controller, native column
endpoint and CodeMirror completion source; metadata remains device/session scoped.
SQL history storage, stable time/ID pagination, literal search and connection-qualified
database filtering follow crates/dbx-core/src/persistence/{history,storage}.rs
and apps/desktop/src/stores/historyStore.ts. Saved SQL folders, lazy document
loading, rename/move behavior and recent/frequent ranking follow saved_sql.rs,
storage.rs, savedSqlStore.ts and lib/savedSql/{savedSqlFileName,savedSqlHistory}.ts.
The history detail/reuse and SQL library surfaces follow QueryHistory.vue and
the desktop file tree. Fouc adapts them in sql-library-repository.ts,
shared/src/relational-sql-library.ts and the React sql-history/library panels;
workspace-owned SQLite files and transactional document versions replace DBX's
global storage and Vue store. No legacy storage adapter or DBX runtime is loaded.
Table structure metadata, ordinal composite foreign keys, expression/INCLUDE
indexes, constraints, triggers and source browsing follow the corresponding
native driver catalog routines and TableStructureEditor.vue. The adapted
TypeScript implementations are drivers/*-structure.ts and the React structure
browser. Database-provided SQL remains source data, not executable UI code.

Redis binary blob transport, cursor/key scans, bounded string/list/stream reads,
collection browsing and command quoting are adapted from
crates/dbx-drivers/src/db/redis_driver.rs. The Redis surface follows
apps/desktop/src/components/redis/{RedisKeyBrowser,RedisValueViewer}.vue.
Fouc's native implementation lives in backend/device/src/database/redis-*,
shared/src/redis.ts and src/features/connectors/redis/. The Redis connector SVG
is an original Fouc illustration. No DBX runtime module is loaded.
Redis mutation commands, collision guards, expiry preservation and hash/ZSet
rename semantics also follow redis_driver.rs and RedisValueViewer.vue. Fouc's
TypeScript/Lua plans add complete-value guards, ACL preflight and snapshot
compensation; the List deletion marker is generated and checked per operation.
Redis database discovery, optional hash-field TTL metadata and expiry commands,
terminal history/recall and DB selection also follow redis_driver.rs and
RedisKeyBrowser.vue. Fouc verifies SELECT acknowledgements on isolated clients
and stores bounded history under the owning workspace and saved connection.
INFO section browsing, metric cards, refresh/search/copy and sortable slowlog
details follow RedisDashboard.vue, RedisSlowlogPanel.vue and redis_driver.rs.
Fouc adapts them in redis-observability.ts, redis-dashboard.tsx and
redis-slowlog.tsx with lossless counters/arguments and scoped polling cleanup.
Stream groups, consumers, Pending, optional Lag and inclusive cursor lookahead
follow redis_driver.rs, redis_ops.rs and RedisValueViewer.vue. Fouc adapts the
read commands in redis-stream.ts and the drill-down surface in
redis-stream-groups.tsx, preserving byte names and 64-bit IDs with request
cancellation and explicit unknown/stale/error states.
Realtime MONITOR command detection, dedicated connection lifetime, stopped and
failed states, 1000-row retention and per-line bounds follow lib/redis/redisMonitor.ts,
query/redis_ops.rs, redis_driver.rs and dbx-web/routes/redis_pubsub_ws.rs. Fouc's
redis-monitor.ts and use-redis-monitor.ts use an authenticated NDJSON stream,
bounded pending batches and scoped cancellation instead of DBX WebSockets.
Pub/Sub channel/pattern subscriptions, disconnect/reconnect restoration, message
retention and publication follow RedisPubSubPanel.vue, redis_ops.rs,
redis_driver.rs and redis_pubsub_ws.rs. Fouc adapts them in redis-pubsub*.ts/tsx
with acknowledged subscription state, byte-preserving RESP2 parsing, scoped
NDJSON capture IDs and explicit publication review through the existing write grant.
RedisJSON root document reads/sets and inline draft/review behavior follow
redis_driver.rs, RedisValueViewer.vue and RedisJsonEditor.vue. The JSON token
formatter, Unicode display decoder and bounded display-to-source edit mapping
are adapted from apps/desktop/src/lib/common/safeJsonFormat.ts into
shared/src/json-source.ts; unused Number-wrapper/stringify helpers are omitted.
Fouc's React CodeMirror editor and existing single-use mutation plans preserve
raw request numbers, byte keys, exact expiry and conflict/permission guards.
